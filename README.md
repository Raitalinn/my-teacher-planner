# My Teacher Planner — Local-first PWA

เว็บแอปสำหรับครูคนเดียว เก็บตารางสอน แผนการสอน บันทึกหลังสอน และงานใน IndexedDB **ของเบราว์เซอร์บนเครื่องที่ใช้** ไม่มี backend และไม่มีการส่งข้อมูลขึ้นเซิร์ฟเวอร์จากแอปนี้

## เริ่มใช้งาน

1. เปิดโฟลเดอร์นี้ในคอมพิวเตอร์และรันเว็บเซิร์ฟเวอร์ภายในเครื่อง เช่น `python -m http.server 8000` แล้วเปิด `http://localhost:8000` (อย่าเปิด `index.html` ผ่าน `file://` เพื่อใช้ PWA ให้ครบ)
2. บนมือถือ สำหรับการติดตั้ง PWA และออฟไลน์ควรเผยแพร่ไฟล์ static ผ่าน **HTTPS** (เช่นโฮสต์ static โดยไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์) แล้วเปิดลิงก์ในเบราว์เซอร์และเลือก "เพิ่มไปยังหน้าจอหลัก"; ข้อมูล IndexedDB ยังอยู่บนมือถือแต่ละเครื่องเอง
3. แอปมีตารางสอนตัวอย่างภาคเรียน 2/2569 ให้แล้ว โดยนับ 16 คาบสอน และ 4 คาบกิจกรรม (18 รายการเนื่องจากกิจกรรม 2 รายการกินเวลาอย่างละ 2 คาบ)
4. สำรองข้อมูลเป็น JSON จากเมนู **เพิ่มเติม > สำรองและกู้คืน** อย่างสม่ำเสมอ สามารถใช้กู้คืนบนอุปกรณ์อื่นได้ด้วยตนเอง

## ข้อจำกัดสำคัญ

- การเปิดบนมือถือและคอม **ไม่ได้ซิงก์ข้อมูลกัน** โดยอัตโนมัติ เพราะแต่ละเบราว์เซอร์มีฐานข้อมูลคนละชุด
- หากลบข้อมูลเว็บไซต์ ถอนการติดตั้งพร้อมข้อมูล ล้างเบราว์เซอร์ ใช้โหมดส่วนตัว หรือระบบจัดเก็บข้อมูลถูกคืนพื้นที่ ข้อมูลอาจสูญหายได้
- HTTPS จำเป็นต่อการลงทะเบียน Service Worker/PWA ในการใช้งานจริงบนมือถือ (ยกเว้น localhost)
- ไฟล์ JSON เป็นข้อมูลสำรอง **ไม่เข้ารหัส** โปรดเก็บอย่างปลอดภัยโดยเฉพาะหากบันทึกข้อมูลนักเรียน
- แอปนี้เป็นเวอร์ชันใช้งานส่วนตัว เริ่มต้นด้วยข้อมูลตารางสอนจากภาพที่ส่งมา ไม่ใช่ระบบบัญชีผู้ใช้/ซิงก์ข้ามอุปกรณ์
